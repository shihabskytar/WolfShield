# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: (pre-release, best effort) |

## Reporting a Vulnerability

Do **not** open a public issue for a suspected vulnerability.

Report it privately by opening a GitHub Security Advisory on this repository,
or by contacting a maintainer listed on the repository. Include:

- a description of the issue and its impact,
- steps to reproduce, if safe to share,
- the version / commit you tested.

We will acknowledge reports promptly, investigate, and coordinate a fix
before public disclosure. We do not run a paid bug bounty.

## Scope and promises

WolfShield is offline-first and does not upload your messages, clipboard
contents, or file contents to any server in the MVP. See docs/THREAT_MODEL.md
for what the app reads, what it never stores, and residual risks.

Do not include personal data (phone numbers, OTPs, account numbers, emails)
in any public issue, fixture, or pull request. See CONTRIBUTING.md.
